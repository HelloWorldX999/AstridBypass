## Loxes Vakası

2011 doğumlu **Buğra** isimli bu genç arkadaşımızın prim yapma ve ünlenme çabalarından bahsedeceğiz.

Kendisini nereden tanıyoruz diye soracak olursanız; çeşitli hile yazılımlarını ve anti-cheat yazılım markalarını sözde kırma girişimleriyle gündeme gelen bir isim olduğunu söyleyebiliriz.

- Geçmişte reşit olmayan kız çocuklarını tehdit ve şantaj yoluyla elde ettiği fotoğrafları yayarak ün kazanmaya çalışmasıyla tanınmaktadır.
- Sonraki dönemlerde kendisini **anti-cheat yetkilisi** gibi gösteren sahte paylaşımlarla FiveM piyasasında defalarca gündeme gelmeye çalışmıştır.
- `cheatglobal.com` adlı forumda da aktif olduğunu görmekteyiz.

Forumda açtığı konuları incelediğimizde, yayımladığı sahte ve yanıltıcı içeriklerin yanı sıra **yapay zekâ** kullanılarak hazırlanmış paylaşımlarla da karşılaşmaktayız.

Sonraki süreçte ise herkese açık projeler üzerinden **Astrid Bypass** adıyla bir proje ortaya çıkarmıştır. Bu proje, insanları kandırarak maddi kazanç elde etmeye yönelik bir dolandırıcılık girişimidir.

Bu nedenle Astrid Bypass projesini yalnızca teknik açıdan değil, arkasındaki süreci ve kullanıcıları nasıl etkilediğini de göz önünde bulundurarak inceleyeceğiz.

## Marka Taklidi ve İftira Kampanyaları

Astrid Bypass markasının bir diğer dikkat çekici yanı, kendi altyapısını geliştirmek yerine **başka hile markalarının altyapılarını talep etmesi**, bu talepleri reddedilince de ilgili platformlardan **banlanmasıdır**. Banlanmasının ardından ise haklı olduğunu göstermek adına **asılsız / iftira niteliğinde konular** açarak kamuoyunu yanıltmaya çalışmıştır.

### Davranış Örüntüsü

- **Altyapı Talebi:** Köklü ve bilinen hile markalarına başvurarak altyapı, kaynak kodu veya ortaklık talebinde bulunmuştur.
- **Red ve Banlanma:** Talepleri kabul görmeyince ilgili topluluklar ve forumlar tarafından **uzaklaştırılmış / banlanmıştır.**
- **İftira Konuları:** Banlanmasının hemen ardından karşı tarafı **RAT dağıtma, zararlı yazılım gömme, kullanıcı dolandırma** gibi iddialarla suçlayan sahte konular açmıştır.
- **Arayüz Kopyalama:** Başka hile markalarının **web sitesi, panel ve launcher arayüzlerini** neredeyse birebir kopyalayarak kullanıcıları yanıltmayı amaçlamıştır.
- **Açık Kaynak Sahiplenme:** Diğer markaların GitHub veya forumlarda **açık kaynak** olarak paylaştığı projeleri, kendi geliştirmesiymiş gibi sunmaktadır. Yani teknik olarak ortaya konan hiçbir çalışmanın gerçek sahibi kendisi değildir.

## Teknik İnceleme — Statik Reverse Engineering Raporu

Astrid Bypass v2.5.0 örneği, **IDA Pro** üzerinden statik tersine mühendislik yöntemiyle (sample çalıştırılmadan) analiz edilmiştir. Aşağıda bu analizden çıkan en kritik bulgular yer almaktadır.

### Örnek Kimliği

| Alan | Değer |
|---|---|
| Dosya adı | `RtkAudioService.exe` *(sahte Realtek audio service)* |
| Boyut | 26,426,880 byte (**25.2 MB**) |
| SHA-256 | `4b6b8ad1057d51d25ed767585966974ebdea697ea06e47334c3d3bd095953862` |
| Format | PE32+ x64, MSVC |
| Packer | **VMProtect 3.x** (konfirme) |

Örneğin gerçek adı **Astrid Bypass v2.5.0**'dır; dosya adı ve string referansları (`Software\Microsoft\AudioSrv`, `WinAudioDrv`) ile **Realtek audio servisi** kılığına girmeye çalışmaktadır.

### Kamuflaj Katmanı

- **Dosya adı sahtekârlığı:** `RtkAudioService.exe` → gerçek bir Windows servisiymiş gibi görünür
- **NVIDIA DLL sideload hazırlığı:** `nvspcap64.dll`, `_nvspcaps64.dll` gibi NVIDIA sürücü dosyalarını hedefleyen sideload referansları içerir
- **Hedef süreçler:** `nvcontainer.exe`, `NVIDIA Share.exe`, `svchost.exe`, hatta `spotify.exe`

### Geliştirici Kimliği Sızıntısı

VMProtect, binary'nin `.rdata` bölümündeki UTF-16 `__FILE__` assert path'lerini **temizlememiştir.** Analiz sonucu doğrudan okunan dizin yolları:

```
C:\Users\loxes\Desktop\AstridProject - Kopya - Kopya\
```

| Alan | Değer |
|---|---|
| Geliştirici kullanıcı adı | **`loxes`** |
| Proje adı | `AstridProject` |
| Oyun içi nick | **`Loxes`** (ESP preview'da plain string) |
| Dizin ismi | "Kopya - Kopya" → **Türk Windows kullanıcısı** |
| ESP box stilleri | Full Box, Corner Box, 3D Box, **Astrid**, Custom |
| Tema listesi | Fenerbahçe, Beşiktaş, Galatasaray *(ve diğerleri)* |
| UI zaman birimleri | `" saat"`, `" gun "` *(Türkçe, boşluk hatalı)* |

Bu bulgular, projenin **tek geliştiricisinin "loxes" olduğunu** ve Türk olduğunu kesinleştirmektedir.

### Yapay Zekâ ile Üretilmiş Materyaller (DALL-E Kanıtı)

Loader içinde **6 adet PNG** (toplam ~5 MB) gömülüdür. Her birinde **C2PA (Content Credentials)** metadata tespit edilmiştir:

```
gpt-image                  →  OpenAI DALL-E successor ürün ismi
version 2.0                →  gpt-image 2.0 modeli
trainedAlgorithmicMedia    →  IPTC "AI tarafından üretilmiştir" etiketi
OpenAI OpCo, LLC           →  Sertifika X.509 Subject
OpenAI TSA Leaf            →  Zaman damgası otoritesi
```

**Zaman damgası (OpenAI TSA Leaf):**
- `notBefore: 2026-04-08 17:46:26 UTC`

Yani loader içindeki görseller **8 Nisan 2026** civarında DALL-E ile üretilmiştir. Bu, loader'ın bu tarihten sonra derlendiğini matematiksel olarak kanıtlamaktadır. UI metinleri (`Initializing secure session`, `Validating deployment credentials` vb.) de muhtemelen **ChatGPT / Claude** yardımıyla yazılmıştır — bu terminoloji native cheat dev yazımı değildir.

### Toplanan Veriler (Statik Analizden Kesin Bulgular)

Loader, `www.astridbypass.com` adresine HTTPS üzerinden **yalnızca** aşağıdaki verileri gönderir:

| Veri | Format |
|---|---|
| Discord snowflake ID | 18-19 basamaklı numeric *(hesap tespit edilebilirse)* |
| HWID 128-bit hash | `%016llX%016llX` *(CPU + VolumeSerial + MachineGuid + Motherboard)* |
| MAC adresi | İlk network adapter |
| Session nonce + ts | Replay attack önlemi |
| HMAC-SHA256 signature | `BCryptOpenAlgorithmProvider` + pepper |

Operator'un sunucuda tuttuğu kayıt: `discord_id → hwid → mac → plan → expires_at → ip (TLS) → user_agent`

### Anti-Analiz Teknikleri

- **VMProtect 3.x** sanal makine koruması
- `IsDebuggerPresent` + `CheckRemoteDebuggerPresent` + `NtSetInformationThread(ThreadHideFromDebugger)` zinciri
- **`SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`** → OBS / Discord yakalamasından **stream-proof overlay**
- **CFG (Control Flow Guard) devre dışı** (`.fptable` tamamen sıfır)
- **PE header stripped**, **PDB stripped**
- **`.pdata` zehirlemesi** → 3432 `RUNTIME_FUNCTION` entry'si bilerek bozulmuş *(WinDbg / procdump bozma)*
- Debugger tespit edilirse **sessizce exit** — crash/BSOD yok

### Backend Mimarisi

| Alan | Değer |
|---|---|
| Domain | `www.astridbypass.com` |
| Backend framework | **Flask (Python)** *(string `flask` plain olarak bulundu)* |
| Session token | **JWT-benzeri** (`jti`, `iat`, `exp`, `nbf`, `iss`, `aud`, `sub` claim'leri) |
| İmzalama algoritması | **HMAC-SHA256** (`BCRYPT_ALG_HANDLE_HMAC_FLAG`) |
| Uygulama katmanı şifreleme | **YOK** — tüm JSON plaintext |
| Güvenlik | **Yalnızca TLS'den geliyor** |

> ⚠️ Uygulama katmanında AES/GCM/CBC yoktur. **MITM proxy (Fiddler + cert install)** ile tüm trafik açıkça okunabilir. Bu, enterprise grade bir mimari olmaktan uzaktır.

### Kullanılan Kütüphaneler

| Kütüphane | Versiyon |
|---|---|
| nlohmann/json | 3.11.3 |
| Dear ImGui | 1.91.9 WIP |
| stb_truetype / rect_pack / textedit | embedded |
| Poppins font | SemiBold + Medium TTF |

Bu, klasik ve halka açık bir cheat stack'tir. **Projede özgün bir kütüphane veya yenilik yoktur.**

### Mimari Zayıflıklar

- **IAT weak spot:** `VirtualQueryEx` import slot RVA `0x013a1030` VMP tarafından iki yerde plaintext bırakılmış → dinamik IAT hook pivot noktası
- **`secret` ve `pepper` string'leri plain** → `.rdata:0x14025de1f` ve `0x14025f355`
- **UI metinlerinde Türkçe suffix hatası:** `" gun "`, `" saat"` → geliştiricinin dev deneyimi zayıf
- **Tüm trafik JSON plaintext** → operator loglarını okuyabilir, MITM ile 3. parti de
